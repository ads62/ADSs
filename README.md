# ADS | Agência Digital & Sites

Site institucional em arquivo único (HTML + CSS + JS embutidos), sem dependências externas de build.

## Como publicar no GitHub Pages
1. Crie um repositório novo no GitHub.
2. Suba o arquivo `index.html` (e este README, se quiser) para a raiz do repositório.
3. Vá em Settings > Pages, selecione a branch `main` e a pasta `/root`.
4. Aguarde alguns minutos e o site estará no ar em `https://<seu-usuario>.github.io/<repositorio>/`.

## Editar conteúdo
- Textos em pt/en/es ficam no objeto `dict` dentro da tag `<script>`, no fim do arquivo.
- Número de WhatsApp: procure por `5535988284531` (formato: DDI+DDD+número, sem símbolos).
- Cores e visual: variáveis CSS no topo do `<style>` (`--blue`, `--blue2`, `--cyan`).
