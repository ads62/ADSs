Como publicar no GitHub Pages
Crie um repositório novo no GitHub.
Suba o arquivo `index.html` (e este README, se quiser) para a raiz do repositório.
Vá em Settings > Pages, selecione a branch `main` e a pasta `/root`.
Aguarde alguns minutos e o site estará no ar em `https://<seu-usuario>.github.io/<repositorio>/`.
